# Админ-панель кейсов

Локальная админка для наполнения кейсов без кода: обложка, название, роль, таймлайн,
команда, платформа и произвольные секции с текстом и картинками. Секции можно
добавлять, переименовывать, переставлять и удалять. Сайт двуязычный: русский и
английский, с переключателем в шапке.

## Запуск

```bash
cd maridesign-admin
node server/index.js
```

Открой в браузере:

- **Админка** — секретный адрес печатается в консоли при запуске
  (`http://localhost:4500/manage-<хеш>`), вход по паролю
- **Сайт** — http://localhost:4500/

В админке две вкладки:

| Вкладка | Что редактирует |
|---|---|
| **Кейсы** | Проекты: обложка, название, роль, таймлайн, команда, платформа, секции |
| **Разное** | Страница «Разное»: карточки с картинкой, заголовком и подписью |

Остановить — `Ctrl+C`. Порт меняется переменной окружения или полем `port` в
`data/site.json`:

```bash
PORT=4600 node server/index.js
```

## Как наполнять страницу «Разное»

1. Открой админку и переключись на вкладку **«Разное»** вверху.
2. **Заголовок раздела** и **описание** — необязательные поля над сеткой
   карточек. Пустые строки просто не показываются.
3. **Добавить карточку** — кнопка справа. У каждой карточки:
   - **Картинка** — перетащи файл на превью или нажми на него. Лучше 4:3.
   - **Заголовок** — крупная надпись под картинкой.
   - **Подпись** — мелкий текст, необязательно.
4. Порядок меняется стрелками `↑` `↓` или перетаскиванием за ручку `⠿`.
5. **Сохранить** или `Ctrl+S`. Кнопка «Посмотреть страницу» откроет `/other`.

Шапка с фото, именем и кнопками и футер на этой странице берутся с главной —
править их не нужно, они общие для всего сайта.

## Страница «Резюме»

Адрес — `/resume`. Шапка с фото, именем, описанием и футер берутся с главной,
меняется только кнопка: «Последняя работа» заменена на **«Скачать резюме»**.

Текст резюме лежит в `data/site.json` в блоке `resume`: опыт работы,
инструменты, навыки, образование. Поля двуязычные, как и везде: если английский
не заполнен, показывается русский.

**Файл PDF.** Положи файл в `maridesign-admin/public/` под именем `resume.pdf`.
Пока файла нет, кнопка серая и не ведёт никуда — страница не отдаёт битую
ссылку. Как только файл появится, кнопка сразу станет рабочей, перезапуск не
нужен.

## Как наполнять кейсы

1. **Новый кейс** — кнопка в правом верхнем углу. Появится в списке слева.
2. **Заполни поля.** Первая группа — то, что видно на главной и в шапке кейса:
   название, краткое описание, компания, год, обложка. Вторая — сведения о
   проекте: роль, таймлайн, команда, платформа.
3. **Язык.** Кнопки «Русский» / «English» переключают, какой язык ты сейчас
   редактируешь. Точка `●` рядом с меткой значит, что перевод на второй язык
   заполнен. Если английский не заполнен, на сайте покажется русский текст —
   страница не будет пустой.
4. **Секции.** Кнопка «Добавить секцию» открывает выбор из восьми типов:

   | Тип | Что даёт |
   |---|---|
   | Текст | Заголовок и абзацы. Пустая строка = новый абзац |
   | Изображение | Картинка во всю ширину |
   | Галерея | Сетка картинок, порядок меняется стрелками |
   | Текст + изображение | Две колонки, текст слева |
   | Изображение + текст | Две колонки, картинка слева |
   | Видео | Ссылка на mp4 или на страницу для встраивания |
   | Цитата | Выделенный блок с акцентной полосой |
   | Список | Маркированный список, пункты добавляются по одному |

   У каждой секции есть **название** — оно становится заголовком на странице и
   пунктом в содержании. Если очистить название, секция останется, но заголовка
   не будет.

   Порядок секций — это порядок блоков на странице. Меняй его стрелками `↑` `↓`
   или перетаскиванием за ручку `⠿` слева от названия. Кнопка `⧉` дублирует
   секцию, `▸` сворачивает, `×` удаляет.

5. **Картинки.** Перетащи файл прямо на превью или нажми на него, чтобы выбрать
   в проводнике. Можно и просто вставить ссылку в поле под кнопками. Для
   обложки лучше пропорции 16:9, например 1920×1080.
6. **Сохранить** — кнопка справа вверху или `Ctrl+S`. Пока есть несохранённые
   изменения, браузер предупредит при закрытии вкладки.
7. **Показывать на сайте** — галочка. Снята: кейс остаётся черновиком и на сайте
   не появляется, но его можно посмотреть кнопкой «Просмотр кейса».

## Публичный сайт

Адреса:

- `/` — главная: шапка с аватаром и меню, блок с именем, описанием и двумя
  кнопками, затем сетка проектов
- `/case/<slug>` — страница кейса: кнопка возврата вместо меню, липкая
  навигация по разделам, в конце — «Другие проекты»
- `/other` — «Разное»: карточки с картинками и заголовками
- `/resume` — резюме: опыт работы, инструменты, навыки, образование; кнопка
  скачивания PDF вместо «Последней работы»
- `?lang=ru` или `?lang=en` — язык; переключатель в шапке сохраняет текущую страницу

Структура страниц повторяет экспорт Framer:

| Блок | Что внутри |
|---|---|
| Шапка | Плавающая пилюля сверху по центру: аватар, «Проекты», «Разное», «Обо мне», «Резюме», переключатель RU/EN |
| Герой | Аватар, имя, описание, кнопки «Последняя работа» и «Обсудить проект» |
| Сетка | Карточки в две колонки, отступы по 64px до краёв (на широком экране) |
| Кейс | Кнопка «Все проекты», заголовок, обложка, липкая навигация по разделам, метаданные, секции |
| Другие проекты | Четыре карточки под кейсом |
| Футер | Аватар и ФИО, описание, «Контакты» с почтой и телеграмом, «Ссылки» на все страницы, © год |

При прокрутке кейса верхняя навигация помечает текущий раздел тёмной плашкой.
Логика в `public/case-nav.js`.

Шрифты, цвета и типографика взяты с текущего сайта Framer: Manrope для заголовков,
Inter для текста, Geist для интерфейсных надписей, акцент `#4513eb`, фон `#fcfcfc`.

Раскладка главной страницы повторяет экспорт Framer по числам из его таблицы
стилей, а не на глаз: секция `max-width 1280px` с отступами `0 64px` и шагом
блоков `80px`, сетка в две колонки с зазором `24px`, обложка с пропорцией 4:3 и
радиусом `8px`, подпись Manrope 14px/600/1.5. На ширине до 810px сетка
становится одноколочной, отступы — `0 20px`, шаг — `60px`, заголовок — 34px.
Это те же контрольные точки, что и в исходном сайте. Проверить совпадение можно
в инспекторе браузера: значения в `public/site.css` указаны рядом с комментарием,
откуда они взяты.

## Где лежат данные

```
data/
  site.json        название, аватар, меню, герой, контакты, футер, резюме
  admin.json       секретный путь админки, хеш пароля и ключ подписи сессии
  cases/*.json     по файлу на кейс
  pages.json       страницы с карточками (сейчас — «Разное»)
  uploads/         загруженные картинки и видео
public/
  resume.pdf       файл резюме для скачивания
```

Файлы обычные, читаемые. Копируй папку `data` для бэкапа. Сайт и админка читают
одни и те же файлы: сохранил кейс — сразу видно на сайте, перезапуск не нужен.

Запись атомарная: сначала пишется временный файл, потом он заменяет основной.
Если что-то прервётся, старый файл останется целым.

## Как выложить на сервер

Админка не нужна на хостинге — она только для наполнения. Есть два варианта.

**Вариант 1: отдать статику.** Прогони сборку:

```bash
node server/build.js
```

Появится папка `dist/` с готовыми HTML, CSS и ассетами. Её можно залить на любой
хостинг статики. При этом админка не работает, а контент фиксируется на момент
сборки.

**Вариант 2: держать сервер.** Скопируй на сервер папку `maridesign-admin`
целиком (без `node_modules` — зависимостей нет), затем:

```bash
node server/index.js
```

Админка доступна по секретному адресу, который печатается в консоли при запуске
(вида `/manage-<хеш>`), и защищена паролем с формой входа — отдельный nginx
basic auth не нужен, всё внутри приложения. Пароль генерируется случайным при
первом запуске и печатается в консоли; сменить можно так:

```bash
node server/set-password.js "новый пароль"
```

Секретный путь и ключ подписи сессии лежат в `data/admin.json` (создаётся при
первом запуске). Чтобы сменить и сам путь, удали `data/admin.json` — при
следующем запуске сгенерируется новый.

Проксировать наружу нужно просто всё:

```nginx
location / {
    proxy_pass http://127.0.0.1:4500;
}
```

## Импорт кейсов из Framer

Если нужно перенести существующие кейсы, положи папку экспорта
(`maridesignb2b-full`) рядом с `maridesign-admin` и выполни:

```bash
node server/import-framer.js
```

Можно указать путь явно:

```bash
node server/import-framer.js "C:\путь\к\maridesignb2b-full"
```

Импортируются метаданные: название, slug, компания, год, краткое описание, роль,
таймлайн, команда, платформа и обложка. **Секции не импортируются** — они лежат во
внутреннем формате Framer без документации, и вычитывать их вслепую значит
рисковать смешиванием текста между кейсами. Секции переносятся вручную в админке,
по одному разу на кейс.

## Ограничения

- Приложение слушает `127.0.0.1`, то есть доступно только с твоего компьютера.
- Запросы к `/api/*` и сама админка требуют сессионную cookie, которую выдаёт
  форма входа. Cookie подписана ключом из `data/admin.json` и помечена
  `HttpOnly` и `SameSite=Lax`, поэтому чужой сайт не может через браузер
  запустить запись в твои данные.
- Админка отдаётся с заголовком `X-Robots-Tag: noindex`, а `/robots.txt`
  запрещает индексацию всего сайта.
- Ограничения на файл при загрузке — 20 МБ.
