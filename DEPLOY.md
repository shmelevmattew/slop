# Деплой

Приложение — обычный Node.js-сервер без зависимостей. Его можно запустить
где угодно, где есть Node.js 20+, либо собрать в Docker.

## Timeweb Cloud App Platform

В репозитории есть `Dockerfile` и `.dockerignore`, так что приложение
разворачивается как есть.

### Шаги

1. **Timeweb Cloud → Приложения → Создать приложение.**
2. **Источник:** GitHub → репозиторий `shmelevmattew/slop`, ветка `main`.
3. **Сборка:** выбери **Dockerfile** (файл в корне репозитория). Если
   предлагается выбор языка — тоже подойдёт Node.js, но Dockerfile надёжнее.
4. **Порт:** `3000` (совпадает с `EXPOSE` в Dockerfile).
5. **Переменные окружения:**
   | Переменная | Значение | Зачем |
   |---|---|---|
   | `HOST` | `0.0.0.0` | чтобы приложение было доступно снаружи (в Dockerfile уже задано) |
   | `PORT` | `3000` | порт приложения (в Dockerfile уже задано) |
   | `ADMIN_PASSWORD` | свой пароль | задаёт пароль админки при первом запуске; если не задать — сгенерируется случайный и напечатается в логах |
6. **Диск (volume):** подключи постоянный диск и смонтируй его в **`/app/data`**.
   Без него контент и `data/admin.json` будут теряться при каждом передеплое,
   потому что файловая система контейнера эфемерная.
7. **Деплой.** После сборки приложение будет доступно на выданном домене
   (`*.twc1.net`), туда же можно привязать свой домен.

### Где взять адрес админки

Секретный путь админки печатается в логах приложения при старте:

```
Админ-панель:  http://0.0.0.0:3000/manage-<хеш>
```

Он же лежит в `data/admin.json` (поле `path`). Пароль — тот, что задан в
`ADMIN_PASSWORD`, либо сгенерированный (тоже в логах).

### Важно про админку в PaaS

- Без постоянного диска правки теряются при передеплое — подключай volume.
- Если диск не нужен, а нужен только публичный сайт, можно вообще не
  выставлять админку наружу: контент лежит в репозитории (`data/`), а править
  его локально и пушить.

## Свой сервер (VPS)

```bash
# на сервере
git clone https://github.com/shmelevmattew/slop.git /opt/maridesign
cd /opt/maridesign/maridesign-admin
node server/index.js
```

Приложение слушает `127.0.0.1:4500` (по умолчанию), наружу его отдаёт nginx.
Пример systemd-юнита и конфига nginx — в `maridesign-admin/README.md`.
