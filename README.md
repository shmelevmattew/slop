# mariadesigner

Сайт-портфолио дизайнера: локальная админка для наполнения кейсов и публичный
сайт на Node.js без внешних зависимостей.

## Структура

- `maridesign-admin/` — приложение: админка, публичный сайт, API и сборка
  статики. Подробности — в `maridesign-admin/README.md`.
- `maridesignb2b-full/` — исходный экспорт сайта с Framer. Материал для импорта
  кейсов, в рантайме не используется.

## Быстрый старт

```bash
cd maridesign-admin
node server/index.js
```

Админка открывается по секретному адресу, который печатается в консоли при
запуске, сайт — на http://localhost:4500/.
